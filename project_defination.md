Assignment 1: Visitor Photo Slideshow
Objective
Design and build an application using AI tools. You are graded not only on whether it works, but on
the decisions you make, how you direct the AI, and how you catch and fix its mistakes. You may 
use any AI tools you like, but you must be able to explain every part of your submission.
Requirements
Design and develop an application with the following behavior:
• Each visitor is asked for their name and photos. 
• As soon as an upload completes, the photo plays in a slideshow for a specific duration on a 
smart TV or computer display. 
• If the person is visiting again, the slideshow also plays their previous photos. 
• You are free to assume any gaps in the requirements, but you must document every 
assumption in ASSUMPTIONS.md. 
Your design must address:
• How a returning visitor is identified
• Privacy and consent, since photos of people are displayed publicly 
• File validation, upload size limits, and what happens when several people upload at once 
Repository Requirements
File / item What it must include
README.md What the app does, tech stack, setup and run instructions, and a deployed 
link if available
ASSUMPTIONS.md Every gap you filled and why you chose that option
AI_LOG.md 5 to 10 key prompts or interactions, including at least 2 cases where the AI 
was wrong, how you noticed, and how you fixed it
ARCHITECTURE.md Stack choice with reasons, data model, and at least one diagram
Tests Automated tests, or a documented manual test plan with results
.env.example Placeholder values only. Never commit API keys, passwords, or secrets.
Commit history Regular, meaningful commits showing how the project evolved. A single 
commit of the final code will lose marks.
Submission Rules
• Submit the link to one public GitHub repository. 
• The repository must be accessible without login. 
• You may be asked to attend a short live demo.
